# 🎓 VNU AI Quiz 

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

> An intelligent, open-source quiz platform designed for students at Vietnam National University of Science (VNU-HUS). 
> **VNU AI Quiz** leverages artificial intelligence to create an engaging, dynamic, and personalized learning experience.

---

## ✨ Features

*   **🤖 AI-Powered Question Generation:** Automatically generate relevant and challenging questions tailored to VNU curriculums.
*   **🎨 Minimalist UI/UX:** A clean, user-friendly interface designed for focus and ease of use.
*   **🌓 Dark/Light Mode:** Seamlessly switch between themes for comfortable studying at any time of day.
*   **⚡ Fast & Responsive:** Built for speed, ensuring a smooth experience across all devices.
*   **📊 Performance Tracking:** (Planned) Track your progress and identify areas for improvement.

## 🚀 Getting Started (Local Development)

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

*   A modern web browser (Chrome, Firefox, Safari, Edge)
*   [Node.js](https://nodejs.org/) (If the project includes a backend or build tools - *Adjust this based on actual requirements*)
*   [Git](https://git-scm.com/)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/liviaisthebest911-alt/vnuaiquiz.git
    cd vnuaiquiz
    ```

2.  **Open the Application:**
    *   **Simple Front-End:** If it's a static site, you can simply open `index.html` in your browser.
    *   **Local Server:** For a better development experience, run a local server:
        ```bash
        # Using Python 3
        python3 -m http.server 8000
        # Then visit http://localhost:8000
        ```

3.  **Environment Variables (If applicable):**
    *   Copy the `.env.example` file to `.env` or `.env.local` and configure your API keys (e.g., OpenAI, Gemini) if required.
    *   *Note: Never commit your actual `.env` file to version control.*
