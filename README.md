# VNU Digital & AI Quiz

Website React + Vite để ôn tập và thi thử môn
**Nhập môn công nghệ số và Trí tuệ nhân tạo**.

## Tính năng

- Dashboard thống kê câu hỏi, chương, bài thi, bookmark và tiến độ.
- Ôn tập theo chương.
- Phản hồi đúng/sai tức thì.
- Hiển thị lời giải chi tiết.
- Đánh dấu câu hỏi khó bằng LocalStorage.
- Thi thử 30 phút.
- Tối đa 40 câu.
- Random câu hỏi từ toàn bộ ngân hàng.
- Matrix grid để nhảy tới câu bất kỳ.
- Nộp bài có xác nhận.
- Tự động chấm điểm /10.
- Hiển thị độ chính xác.
- Xem lại từng câu.
- Import/replace ngân hàng câu hỏi bằng JSON.
- Tải JSON mẫu.
- Vercel-ready SPA.

## Yêu cầu môi trường

Vite 8 yêu cầu Node.js 20.19+
hoặc 22.12+.

Nên dùng Node.js LTS mới.
